# Sales_DashboardVisualization-
Sales Performance and Revenue Dashboard
Welcome to my sales dashboard project. I built this interactive report to help businesses analyze sales performance, track total revenue, and identify top-selling products and key international customer locations.

About the Project
I created this project to show how raw sales data can be turned into a clear, easy-to-understand visual report. The dashboard allows managers and team members to view high-level business results at a glance and explore performance across three years (2009 to 2011).

Key Highlights and Features
Summary Scorecards: Displays total sales revenue ($19.29 million) alongside individual year-by-year sales breakdowns.

Sales by Location: Uses a clear bar chart to show revenue by country, highlighting top markets such as the United Kingdom, Ireland, and the Netherlands.

Product Insights: Uses a visual chart to highlight top-selling products so businesses can quickly identify best-sellers.

Custom Calculations: Built custom mathematical formulas to multiply product prices by quantities sold, and created filters to break down sales by specific years and regions.

Professional Layout: Designed with a clean, dark background and easy-to-read text for a modern business look.

Tools Used
Power BI Desktop: Used to create the visual charts, dashboard layout, and overall report design.

Power Query: Used to clean and organize the raw data before building the charts.
